PROJECT 1 — IMPERIUM TRADERS CLUB (ITC)

1. Extract this ZIP.
2. Open index.html to preview where supported. For public-market feeds, web app installation, and service worker features, publish with HTTPS (GitHub Pages is supported).
3. To publish with GitHub Pages, upload the contents of the extracted folder (not the enclosing folder) into the root of your repository, then enable Settings → Pages → Deploy from a branch → main → /(root).
4. Reopen the deployed site and refresh it once if an older installed version is cached.
5. On Android Chrome, use the browser menu and choose Install app or Add to Home screen.

My Bots: users can upload their own Deriv DBot XML file for inspection in Blockly. The website does not provide XML download buttons. AI Bots are kept in a separate tab and link to Free Bots. Always inspect imported blocks and test only in demo mode first.

Signal Alert Desk: open Signals, fill in the alert setup, and start the 10-minute timer. Use Copy alert message and open Telegram/WhatsApp to post it manually. When the timer expires, copy the expiry update and post it manually. Automatic group posting is not included in this static website package.

Safety: market tick frequencies describe past observations, not guaranteed predictions. Keep private tokens and service credentials out of this ZIP/repository. Real trading is not enabled by the demo bot runner.
