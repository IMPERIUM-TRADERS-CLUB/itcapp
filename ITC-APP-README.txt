IMPERIUM TRADERS CLUB — WEB APP / PWA

This release contains the static website for GitHub Pages. It does not include Android Studio project files or a built APK.

After publishing to GitHub Pages over HTTPS, open the public website in Chrome for Android and choose Menu → Install app or Add to Home screen.

The current bot runner is simulation-only. Public market ticks can be live when the connection indicator confirms the feed; the app does not place live Deriv orders. Never put private API tokens into GitHub or source code.
