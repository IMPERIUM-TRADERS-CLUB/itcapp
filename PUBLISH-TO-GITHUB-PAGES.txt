IMPERIUM TRADERS CLUB — WEB APP PACKAGE (VERSION 19)

PUBLISH WITH GITHUB PAGES
1. Open the repository: https://github.com/Thuglarlevon3560/imperiumtradersclub
2. Extract this ZIP. Upload the CONTENTS of the extracted folder into the repository's main/root folder (index.html, style.css, app.js, market-live.js, config.js, manifest.webmanifest, sw.js, icons/, bots/, and the other included files). Do not upload the enclosing folder as a nested folder unless you configure Pages for that path.
3. Commit the files to the main branch.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for GitHub Pages to publish. Confirm the exact URL shown in Settings > Pages.
7. Open the published URL in Chrome on Android. Use the browser menu > Install app or Add to Home screen.

IMPORTANT
- GitHub Pages supplies HTTPS, required for service workers/PWA installation.
- Never commit Deriv API tokens or account secrets. Do not put a token in config.js or this repository.
- The public market stream is read-only and needs an internet connection. If the header says CONNECTING MARKET, the live feed is not confirmed yet.
- Bot Run remains a local demo simulation. The supplied DBot XML files are retained for visual inspection/editing, not verified live execution.
- Blockly and embedded TradingView content load from external providers, so their full features need an internet connection.
- After replacing the files, close the old installed app/browser tab and reload the website. The updated service-worker cache is versioned to v19.
