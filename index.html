FREQUENTLY ASKED QUESTIONS
Before you begin
Is the market data real?
The public market chart and quote are live when the Deriv connection status says LIVE. Balance, performance metrics and example signal descriptions remain demo content.
Does Run simulation place a trade?
No. It creates a local run log only. The account connection can verify authorization separately, but it does not enable live bot trading in this version.
Is my Deriv API token saved?
No. The Settings token field is cleared when Connect is pressed, and this page does not save the token to localStorage, source files, or the package. Disconnect closes the authorized session. Prefer minimum permissions, and never share the token in chat or public repositories.
Can this be hosted on GitHub Pages?
Yes. The front-end files can be served as a static website. Any live API integration, authentication, database or private credentials should be handled separately and securely.
